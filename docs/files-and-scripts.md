# Назначение файлов, скриптов и осознанные нюансы

## Файлы навыка

|**Файл**|**Назначение**|
|-|-|
|`skill/SKILL.md`|Полный алгоритм разведки: шаги 1-15, обязательные правила, обработка ошибок. Скопируйте в `skills/comp-intel/` вашего Hermes.|
|`skill/references/company-capabilities.md`|Профиль ВАШЕЙ компании для скоринга лида (рейтинг 0-10). Заполняется вручную. Здесь можно разместить каталоги, список оборудования с его параметрами, целевую аудиторию, УТП и т.д.|
|`skill/references/tender-parsing.md`|Справка по закупкам: ЕИС, tochka, b2b-center, ФРП.|
|`skill/scripts/lead\_search.py` → `company\_search\_helper.py`|Вспомогательный runner: базовый поиск + list-org одним вызовом.|
|`skill/scripts/cdp\_parse.py`|CDP-парсер SPA-сайтов (ЕИС, b2b-center, corpmsp) через headless Chromium.|

|**Скрипт**|**Назначение**|

|`search\_all.py`|Главный поиск: DDGS (бэкенды auto→duckduckgo→google→yahoo, region ru-ru), фильтр агрегаторов (DOMAIN\_BLACKLIST), `--fetch` с компакт-текстом ≤12000 симв.|
|`requisites\_parser.py`|Реквизиты/финансы/директор/госконтракты/арбитраж. **Checko API → HTML-фолбэк** автоматически. Фолбэк-агрегаторы find-org.net/buxbalans при ошибках Checko.|
|`domain\_probe.py`|DNS/TLS/поддомены/wayback. `--tld-alts` — проверка .ru↔.com одним вызовом. LLM-компактный JSON по умолчанию, `--json` — полный.|
|`hh\_vacancies.py`|Вакансии через веб-поиск (api.hh.ru закрыт для гостя). Гиганты (≥6000 вакансий) — 2 страницы. Счётчик производственных вакансий, как пример косвенной потребности. Можете заменить под свои нужды.|
|`vk\_group\_parser.py`|Сообщество ВК: описание, контакты, посты (≤2 лет, ≤100 шт., ≤20000 симв.). Обязательная валидация названия против компании.|
|`vk\_people\_search.py`|Шаблоны ручного поиска сотрудников ВК + users.search при пользовательском токене + DDGS-упоминания.|
|`tenchat\_parser.py`|TenChat: карточка по ОГРН + сотрудники (ФИО/должность/ссылка). Кеш 30 дней.|
|`tgstat\_parser.py`|Telegram-канал: подписчики, описание, последние посты (telegram-dialogs.ru → tgstat-сниппеты).|
|`zakupki\_223\_parser.py`|ЕИС 223-ФЗ: договоры + план (пагинация, фильтр заказчика).|
|`zakupki\_tochka\_parser.py`|tochka.com: закупки из Next.js-потока (балансный проход по скобкам).|
|`bitrix\_sync.py`|Выгрузка в Б24: поля, таймлайн (BBCode), галки. Идемпотентен.|

## Осознанные нюансы (принятые компромиссы)

1. **Телефоны в Checko API (по крайней мере, на бесплатном тарифе) замаскированы** (`+791\*\*\*\*0464`) — политика API. Полные номера
берём из HTML-карточки или сайта. Нормализация к `+7XXXXXXXXXX` делается перед записью в Б24.
2. **Файлы: xls/xlsx/pdf серия — обязательный шаг.** Даже если по типу компании файлы «заведомо
не ожидаются» — запросы выполняются; пустой результат — тоже результат (фиксируется).
3. **Идемпотентность таймлайна**: повторный bitrix\_sync не дублирует карточку (маркер
`.b24\_synced` в папке разведки) — защита от «комментарий выгружается дважды».
4. **Ликвидированные компании — ранний выход**: при ≥2 независимых подтверждениях ликвидации
конвейер останавливается, сразу комментарий-подтверждения в таймлайн + галки в Б24.
Полная карточка не пишется. Рейтинг 1-2.
5. **Тёзки**: новости/контакты сверяются по ИНН перед записью; не совпало — «тёзка, исключить».
6. **Blacklist агрегаторов**: rusprofile/СПАРК/Checko и др. отсекаются на уровне search\_all
(дублируют ЕГРЮЛ), чтобы не тратить токены. list-org — отдельный шаг (полезнее).
7. **Финансы**: строки 2110/2400/1600/1300 из API-отчётности; HTML-парсинг — по заголовкам
(«Выручка» может встречаться на странице 3+ раз), а не по позициям строк.
8. **Mojibake и 404**: поддомены с битой кодировкой или не-2xx статусом отбрасываются, а не
попадают в результат с мусорным title.
9. **Гиганты hh**: 2 страницы (40 вакансий) — для производственного профиля достаточно;
счётчик производственных вакансий в выводе проверяет репрезентативность.
10. **Токены и время**: в карточке строка «Затрачено: \~N мин, \~Nк токенов» — приблизительная
оценка агентом (точные токены доступны только через state.db Hermes).
11. **Пагинация**: ЕИС реестр — до 5 страниц (`max\_pages`), остановка на пустой; tochka — до
первой пустой страницы (max\_pages=5).
12. **Валидация VK-группы**: не совпало название → JSON `validation.passed=false` +
`candidate\_group` (для ручной сверки) — случайные группы по смысловому совпадению отсекаются.
