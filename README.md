# comp\_intel — автоматическая разведка компаний для отдела продаж

Навык и набор парсеров для глубокого исследования российских компаний:
от поисковой выдачи и ЕГРЮЛ до соцсетей, вакансий и госзакупок — с готовой
карточкой для отдела продаж и выгрузкой в Битрикс24.

Стоимость разведки: ~3.42-7.69 руб. / 0.04-0.09 $
Длительность разведки: ~6-10 минут
Используемая модель: glm-5.3-flash (Ollama, тариф Pro)

## Чем полезен

Менеджер, готовящий встречу с незнакомым контрагентом, тратит 1–3 часа на ручную разведку (если сравнивать резултаты разведки по качеству с теми, что выдает этот агент):
поиск в 5-6 системах, агрегаторы, соцсети, закупки, финансы. Этот конвейер делает то же
за 5-10 минут и оставляет структурированную карточку со ссылками на источники.

В Examles Вы можете уидеть примеры готовых карточек разведки по компаниям, а также пример рекомендаций, которые ИИ агент дает по каждому проходу.
Также в папку разведки будут попадать логи и другие файлы, чтобы Вы могли улучшить результаты именно на Ваших задачах.


#### Что находит и делает:

* **Контакты по открытым источникам и свзязи** — найдет связи и контакты для целей продаж;
* **Реквизиты и финансы** — Checko (API или HTML), ЕГРЮЛ, уставный капитал, директор с ИНН;
* **Домены и инфраструктура** — DNS/TLS/поддомены/wayback, альтернативные TLD (.ru ↔ .com);
* **Официальный сайт** — контакты, страницы «Поставщикам/Партнёрам», меню-карта;
* **Соцсети** — VK-сообщество (с валидацией названия), TenChat-сотрудники, Telegram-каналы;
* **Вакансии hh.ru** — производственный профиль работодателя;
* **Госзакупки** — ЕИС 223-ФЗ, tochka.com, арбитражные дела (kad.arbitr.ru), Федресурс;
* **Файлы** — поисковая серия xls/xlsx/pdf (прайсы, реестры, потребности);
* **Скоринг** — рейтинг интереса 0–10 под профиль вашей компании;
* **Новости и другие источники** — ищет новости, связанные с компанией и другую полезную информацию;
* **Выгрузка в Битрикс24** — поля компании + карточка в таймлайн + отметки.



#### Точки входа для продаж, которые подсвечивает конвейер:

* страницы «Поставщикам/Партнёрам/Тендерам» на сайте компании (прямые контакты закупок);
* активные закупки и планы (номер, цена, срок, ссылка на извещение);
* связанная группа компаний (по MX, учредителям, филиалам);
* «кто преемники» — если компания ликвидирована (активы купил другой, у него и потребность).

## Процесс (кратко)

|Шаг|Что делается|Инструмент|
|-|-|-|
|1|Поиск по названию (без ОПФ, с городом)|`search_all.py`|
|2|Уточняющий поиск по ИНН|`search_all.py`|
|3|Реквизиты/финансы/директор/госконтракты|`requisites_parser.py` (API → HTML)|
|4|Домены, DNS, TLS, поддомены, wayback|`domain_probe.py --tld-alts`|
|5|Официальный сайт (меню = карта URL)|`fetch_url.py` / `recover_page.py`|
|6|Соцсети: VK, TenChat, Telegram|`vk_group_parser.py`, `tenchat_parser.py`, `tgstat_parser.py`|
|7|Вакансии hh.ru|`hh_vacancies.py`|
|8|Файловая серия (xls/xlsx/pdf)|`search_all.py` (обязательный шаг)|
|9|Новости ≤3 лет, закупки ЕИС 223 + tochka|`search_all.py`, `zakupki_223_parser.py`, `zakupki_tochka_parser.py`|
|10|Рейтинг, MD-карточка, выгрузка в Б24|`bitrix_sync.py`|

Полное описание — в `skill/SKILL.md` (шаги 1-15, обязательные правила, обработка ошибок).



## Опции (подключаемые модули)



Важный момент: в данном скилле не используется прокси. Если будете запускать на очень больших объемах - рекомендуется подключить. Для анализа 20-40 компаний в день не критично.



* **Битрикс24** (коробка или облако): передача `company_id` из бизнес-процесса — синк
записывает поля, карточку в таймлайн (BBCode), галку «Есть данные разведки».
* **Checko API** (тариф 100 запросов/день): карточка/финансы/госзакупки/арбитраж —
без 429 и капчи; HTML-парсер остаётся автоматическим фолбэком.
* **Google / Yandex**: альтернативные движки поиска (`search_all.py` google|yandex) —
включаются ключами `SERPAPI_KEY` / `YANDEX_USER`+`YANDEX_KEY`.
* **VK API**: сервисный токен (описание группы, посты) или пользовательский (поиск сотрудников).
* **Браузерные методы (подключен по умолчанию)**: ЕИС-SPA, b2b-center, corpmsp — через headless Chromium (`cdp_parse.py`).
* **Wayback/archive.today/Jina (подключен по умолчанию)**: восстановление заблокированных страниц (`recover_page.py`).
